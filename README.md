# 基于对抗生成网络的人脸年龄变换系统

这是《卓越工程实践》课程项目的组内共享工作目录，题目为“基于对抗生成网络的人脸年龄变换系统”。仓库保留课程原始资料、往年文档模板、课堂讨论报告、公开资料检索记录和后续项目文档，方便组员共同查看、讨论和迭代。

├── 需求说明资料/                                     需求文档、课程要求和调研材料归档包

## 推荐阅读顺序

1. 先看 `需求说明资料/02_课程与项目要求/requirements_on_2026_10_21.txt` 和 `whole_tasks.txt`，确认课堂任务与 A-E 技术链。
2. 再看 `需求说明资料/03_调研与检索材料/课堂讨论速览.md`，快速了解课堂汇报内容。
3. 课堂讨论前后重点维护 `需求说明资料/03_调研与检索材料/课堂讨论详细报告.md`。
4. PPT 汇报稿为 `需求说明资料/03_调研与检索材料/人脸年龄变换系统_需求调研汇报.pptx`，内容核对见同目录的 `同学PPT内容核对记录.md`。
5. 需要核对网页原文、论文摘要和作者仓库信息时，查看 `需求说明资料/03_调研与检索材料/检索记录` 和 `来源清单.json`。
6. 后续需求、概要设计、详细设计、测试和周报文档继续放入 `需求说明资料` 或新建对应目录，并保持需求编号、设计模块和测试用例之间的对应关系。
7. v5 网页原型和使用说明位于 `原型/`。

## 资料说明

需求文档建议先看 [规范版 v0.3](需求说明资料/01_需求规格说明书/人脸年龄变换系统_软件需求规格说明书_规范版.docx)，并结合 [规范化说明](需求说明资料/01_需求规格说明书/需求规格说明书_规范化说明.md) 核对改动。该版按《附录 G-2 产品需求规格说明书》组织，保留 22 项 FR 和原稿实验记录；范围、性能目标和待确认事项仍需小组与指导教师审阅。

- 原始课程文件和两个模板压缩包按课程工作目录原样保留。
- 调研报告中的应用宣传内容来自公开官网、应用商店简介或官方文章；论文内容来自原始论文页面或 arXiv 摘要。
- 目前的产品资料属于需求前期检索，尚未代表本组完成应用安装、模型推理、训练或性能实测。
- `原型/人脸年龄变换原型_v5.html` 是可演示的交互原型；年龄估计和年龄变换仍是占位效果，详细边界见同目录使用说明。
- `tmp` 目录是本地检索过程中的临时目录，不属于组内共享资料，因此被 Git 忽略。

## 协作约定

- 修改报告时保留检索日期、来源链接和不确定性说明。
- 不要把“网页宣传效果”直接写成本组已达到的指标。
- 课堂确认的范围、人员分工、硬件条件和性能指标及时写回详细报告的“课堂结论记录区”。
- 组员提交新的需求、设计或测试材料时，文件名注明日期和文档类型。
