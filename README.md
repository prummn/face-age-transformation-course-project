## 快速启动

电脑需安装 Python 3，推荐使用较新的 Chrome 或 Edge。运行网页不需要 Node.js、npm，也不需要安装 Python 第三方依赖。

先下载仓库并解压，或用 Git 获取：

```powershell
git clone https://github.com/prummn/face-age-transformation-course-project.git
cd face-age-transformation-course-project
```

在仓库根目录（包含本 README 的目录）打开终端并运行：

```powershell
python 原型/serve.py
```

打开 [http://localhost:65512/](http://localhost:65512/)。Windows 若只有 `py` 命令，可运行 `py -3 原型/serve.py`。使用期间保留终端窗口；按 `Ctrl+C` 停止服务。再次使用时重新执行启动命令即可。

若端口被占用，可改为 `python 原型/serve.py --port 65513`，随后访问 `http://localhost:65513/`。建议通过服务器打开页面，不直接双击 HTML；这样检测运行库和模型可以从仓库本地加载，减少课堂演示对外网的依赖。

### 在手机上演示

电脑与手机连接同一局域网，在电脑运行：

```powershell
python 原型/serve.py --bind 0.0.0.0
```

手机访问 `http://电脑的局域网IP:65512/`，例如 `http://192.168.1.23:65512/`，请替换成实际 IP；Windows 可用 `ipconfig` 查看当前网卡 IPv4 地址。需要允许该服务通过本机防火墙。`0.0.0.0` 是监听地址，手机访问时应使用电脑 IP。

局域网 HTTP 可用于上传照片演示。**手机调用摄像头需要可信 HTTPS**，应将整个 `原型` 目录部署到 HTTPS 静态站点或配置受手机信任的 HTTPS；电脑的 `localhost` 可以使用相机，手机的 `localhost` 则指手机自己。仓库地址用于共享文件，不是已部署的在线演示站点。

## 当前能体验什么

竖屏显示器以 **1080×1920（宽×高）** 为基准整屏展示，镜头、结果与字号随大竖屏适配；横屏电脑窗口保留居中的手机比例预览，手机窄屏全屏取景。显示器先在系统设为纵向，浏览器可按 `F11` 全屏，详见[竖屏演示说明](原型/README.md#竖屏显示器演示2026-10-30)。

拍照或上传后，单人脸自动继续，多人脸可以点选，检测失败可以手动框选；默认等待所有检测到的人脸姿态、大小与稳定时间合格后自动拍照；使用 30 岁演示占位年龄，无须手填，制作完成自动轮播年龄扉页。可滑动浏览、拖动对比、回贴原图、导出 PNG，并返回主页或再拍一张。现有自动互动流程保留，本轮没有增加手势识别。

| 部分 | 当前状态 |
|---|---|
| 人脸检测与轮廓 | 已接本地 MediaPipe；面部填色为关键点几何掩膜，尚非完整实例分割 |
| 当前年龄 | 真实估龄模型尚未接入，目前固定 30 岁演示占位，非估龄结果；需求最终要求自动估龄，允许手动修正 |
| 年龄变换 | 目前为带明确标注的演示滤镜，尚非真实 GAN 生成 |
| 结果与导航 | 扉页、对比、回贴、拼图、PNG 导出、返回与重拍流程可演示 |
| 硬件与服务 | RK3288 Android 应用、局域网 GPU 服务及实机性能验收仍待完成 |

录屏和网页用于展示交互，不作为真实估龄精度、GAN 效果或目标硬件验收证据。
