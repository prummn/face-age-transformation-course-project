# 基于对抗生成网络的人脸年龄变换系统

这是《卓越工程实践》课程项目的组内共享工作目录，题目为“基于对抗生成网络的人脸年龄变换系统”。仓库保留课程原始资料、往年文档模板、课堂讨论报告、公开资料检索记录和后续项目文档，方便组员共同查看、讨论和迭代。

## 当前目录

```text
.
├── Projects.pdf                         课程项目总体要求
├── requirements_on_2026_10_21.txt      当天课堂讨论要求
├── whole_tasks.txt                      本组 A-E 分点任务
├── 项目文档模板.zip                     往年项目文档模板
├── 卓业工程综合训练文档模板.zip          往年综合训练文档模板
└── 调研
    └── 2026-10-21
        ├── 课堂讨论速览.md
        ├── 课堂讨论详细报告.md
        ├── 项目理解与检索报告.md
        ├── 来源清单.json
        └── 检索记录
```

## 推荐阅读顺序

1. 先看 `requirements_on_2026_10_21.txt` 和 `whole_tasks.txt`，确认当天任务与 A-E 技术链。
2. 再看 `调研/2026-10-21/课堂讨论速览.md`，快速了解课堂汇报内容。
3. 课堂讨论前后重点维护 `调研/2026-10-21/课堂讨论详细报告.md`。
4. 需要核对网页原文、论文摘要和作者仓库信息时，查看 `调研/2026-10-21/检索记录` 和 `来源清单.json`。
5. 后续需求、概要设计、详细设计、测试和周报文档继续放入 `调研` 或新建对应目录，并保持需求编号、设计模块和测试用例之间的对应关系。

## 资料说明

- 原始课程文件和两个模板压缩包按课程工作目录原样保留。
- 调研报告中的应用宣传内容来自公开官网、应用商店简介或官方文章；论文内容来自原始论文页面或 arXiv 摘要。
- 目前的产品资料属于需求前期检索，尚未代表本组完成应用安装、模型推理、训练或性能实测。
- `tmp` 目录是本地检索过程中的临时目录，不属于组内共享资料，因此被 Git 忽略。

## 协作约定

- 修改报告时保留检索日期、来源链接和不确定性说明。
- 不要把“网页宣传效果”直接写成本组已达到的指标。
- 课堂确认的范围、人员分工、硬件条件和性能指标及时写回详细报告的“课堂结论记录区”。
- 组员提交新的需求、设计或测试材料时，文件名注明日期和文档类型。
