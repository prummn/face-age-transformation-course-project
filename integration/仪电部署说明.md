## 运行位置与访问

仓库 `/root/face-age-transformation-course-project`。当前工作区没有 GPU 设备，GPU 必须通过仪电任务池分配。本次创建独立单 GPU 推理任务，配额组 `fdj_gpu_taskpool`、项目 `fdj-infra`、区域 `cn-shanghai-a`；只管理 `deployment/current.json` 记录的本项目任务。平台分配 NVIDIA H200，初始无其他进程。未停止、修改其他任务。

工作区网页网关 `127.0.0.1:65512` → 工作区隧道 `127.0.0.1:18765` → GPU 容器真实后端 `127.0.0.1:8765`。三个推理/网页端口均不对公网监听。当前工作区原 SSH 服务配置 `GatewayPorts yes`，因此另启专用 SSH 监听器 `172.16.25.78:18822`，使用专用受限密钥、`GatewayPorts no`、仅允许远程转发到 `127.0.0.1:18765`、禁止会话及密码认证。密钥在被 Git 忽略的 `deployment/ssh`，不要复制到报告或提交。

在莫贝自己的电脑运行，使用既有 `yicloud` SSH 配置（自动沿用其跳板、账号和端口）：

```sh
ssh -N -o ExitOnForwardFailure=yes -L 65512:127.0.0.1:65512 yicloud
```

相册入口 <http://localhost:65512/>。镜子入口 <http://localhost:65512/人脸年龄变换原型_v5.html?mode=live&experience=mirror>。摄像头在自己电脑浏览器中运行；需要允许 localhost 的摄像头权限。

Windows 若出现 `bind [127.0.0.1]:65512: Permission denied`，表示客户端本地端口绑定被拒绝（可能在系统保留端口段内）。按 Ctrl+C 结束原转发，在自己电脑改用本地 18080，服务器端口仍为 65512：

```powershell
ssh -N -o ExitOnForwardFailure=yes -o UpdateHostKeys=no -L 127.0.0.1:18080:127.0.0.1:65512 yicloud
```

此时访问 <http://localhost:18080/>，镜子入口为 <http://localhost:18080/人脸年龄变换原型_v5.html?mode=live&experience=mirror>。终端常驻且无输出是正常状态。`client_global_hostkeys_prove_confirm: ... bad signature for RSA key` 属于登录后的额外主机密钥自动更新校验；本命令用 `UpdateHostKeys=no` 跳过自动更新，保留正常主机身份验证，不删除 known_hosts，也不修改平台 SSH 服务。

莫贝本机实测 65512、18080 均被 Windows 拒绝绑定，具体是保留端口还是安全软件限制尚未确认。可用 PowerShell 先向 Windows 申请一个实际能绑定的动态端口，释放探测监听后交给 SSH（二者之间存在很短的端口竞争窗口）：

```powershell
$probe = [System.Net.Sockets.TcpListener]::new([System.Net.IPAddress]::Loopback, 0)
$probe.Start()
$demoPort = $probe.LocalEndpoint.Port
$probe.Stop()
Write-Host "浏览器地址：http://localhost:$demoPort/"
ssh -N -o ExitOnForwardFailure=yes -o UpdateHostKeys=no -L "127.0.0.1:${demoPort}:127.0.0.1:65512" yicloud
```

若探测或 SSH 仍被拒绝，请收集客户端 `netsh interface ipv4 show excludedportrange protocol=tcp` 输出继续定位；不要删除系统保留段或关闭防火墙。以上客户端动态端口方案尚待莫贝实际验证，服务器健康检查仍为 ready。

## 重启与停止

在服务器仓库根目录执行。SDK 凭据沿用已有 `YICLOUD_PUBLIC_KEY` / `YICLOUD_SECRET_KEY` 环境变量，仅由工作区 SDK 客户端读取，不传入 GPU 容器、不写入请求或日志。

```sh
python3 integration/deploy_yicloud.py start
python3 integration/deploy_yicloud.py status
python3 integration/deploy_yicloud.py stop
```

`start` 复用尚在运行/排队的本项目任务，或者创建一个新任务，再后台启动 `launch.py --upstream http://127.0.0.1:18765 --port 65512 --no-browser`。本机网关等待真实模型 ready。任务最多运行 24 小时；平台到期后再次 start 可创建新任务。stop 仅停止本项目 receipt 中的 GPU 任务及本项目 PID 对应的网关和专用 SSH 监听器，保留代码、环境、权重和证据。不执行无范围的 pkill。

若首次网络/共享盘加载超过网关默认 300 秒，修复后运行 `python3 integration/deploy_yicloud.py gateway`。若重建工作区导致私网 IP 改变，需同步更新专用 sshd 的 ListenAddress、known_hosts 和 worker 中的 SSH 目标，先停止本项目再更新；不要改平台全局 SSH 配置。

## 环境、代码与权重

- 工作区 Linux x86_64，Python 3.12，约 80 GiB 内存，`/root` 为 GPFS 共享盘（部署时可用约 7.6 TiB）。
- GPU 任务使用平台镜像 `registry.gate.yicloud.com.cn/library/pytorch-training-nvidia:2.6.0-py3.10-cuda12.9-h20-ubuntu22.04-v20260710`。以实际 `device.json` 为准：Python 3.10.12、PyTorch 2.6.0+cu124、CUDA 12.4、NVIDIA 驱动 580.159.04。保留镜像 PyTorch/torchvision。
- GPU 容器独立环境 `/tmp/face-age-demo-venv`，继承镜像基础依赖；仅从 `deployment/wheels` 离线安装辅助依赖。重建任务会重新创建此环境。推理全程使用本地权重，HF_HUB_OFFLINE=1；未安装用于 HuggingFace 在线传输的 hf-xet，pip check 对该未用下载组件的提示不影响本地推理。工作区浏览器工具环境为 `deployment/control-venv`。浏览器在 GPFS 上读取 ICU 数据的 mmap 失败，复制同一浏览器至本地盘 `/tmp/face-age-chrome` 后已验证可启动；重建工作区时需重新复制，未重装系统库。
- SAM 上游固定在 `deployment/SAM` 的 `c1895aef275e702fba7560284dc16df60d65210e`。仅把 `fused_act.py`、`upfirdn2d.py` 替换为仓库原有纯 PyTorch 参考实现；这些运算也支持 CUDA。没有运行带旧昇腾路径的 `patch_sam.sh`，没有引入 torch_npu 或编译旧 CUDA 扩展。
- 通过仓库 `restore.py` 默认清单恢复四个演示模型到 `deployment/model-files/face-age`，逐片与完整文件 SHA256 校验；未使用 `--all`。清单在 `integration/models/weights.json`，最终校验记录在 `deployment/assets-ready.json`。
- 默认仍是 `out/ft_l1/encoder_step1000.pt`、基础 SAM、ConvNeXt-T FairFace 和 YuNet。没有实验权重、Qwen、训练数据或超分模型。
- 源码布局 `deployment/model-files/face-age/src` 链接到本仓库辅助模块与固定 SAM 检出。`sam_npu.py`、`sam_losses.py`、`faceattr.py` 均读取 `FACE_AGE_BASE`，不只修复 backend 的路径。
- backend 通过 `FACE_AGE_DEVICE=cuda:0` 选择平台分配的设备；保留原来的 NPU 默认值。仅抽取 set_device/synchronize 并报告实际设备名。年龄条件、256 对齐、同龄锚点＋原始 SAM 差值、固定噪声和原生 1024 解码保持原逻辑。
- PyTorch 2.6 对旧 checkpoint 的读取在本任务进程中设置 `TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1`。只加载本项目已校验 SHA256 的可信 Release 文件，不修改共享环境。
