# 新机器快速开始

在新服务器的Linux终端执行：

```sh
git clone --single-branch --branch dev/mobei-gan-portable-20261116 https://github.com/prummn/face-age-transformation-course-project.git
cd face-age-transformation-course-project
bash integration/setup_codex_cli.sh --start
```

需要已有 `git`、`python3`、`curl`、`tar`。若缺少，先用服务器包管理器安装对应工具；脚本不修改GPU驱动或系统Python环境。Codex首次下载使用OpenAI官方GitHub发布的Linux独立二进制，固定原机已使用的0.167.1，无须Node.js／npm或sudo；发现已有Codex时直接复用。

脚本首次隐藏询问 **SpacetimeAI API Key**，填写你当前中转站自己的Key。它保存在用户的 `~/.config/face-age-codex/env.sh`，目录700／文件600，不输出、不写入仓库。若环境已提供 `SPACETIMEAI_API_KEY` 则不再询问；后续终端自动加载，直接运行 `codex`。配置有改动时，旧 `config.toml` 在原目录另存带时间戳备份，保留其他工具／项目设置。若继承的复杂TOML无法安全修改，脚本明确停止而不覆盖。

自动配置与原机一致：

```toml
model = "gpt-6.1-sol"
model_provider = "spacetimeai"
model_reasoning_effort = "xhigh"

[model_providers.spacetimeai]
name = "SpacetimeAI"
base_url = "https://spacetimeai.cc"
env_key = "SPACETIMEAI_API_KEY"
wire_api = "responses"
requires_openai_auth = false
```

这里的模型名是中转站现有配置，不代表对OpenAI官方模型可用性的声明。不添加 `/v1`，不执行ChatGPT登录。脚本仅配置并检查CLI能解析配置；中转站余额、模型权限和新机出网由第一次实际会话确认。没有复制原机跳过审批等权限设置。

`--start` 会直接启动Codex，并要求它阅读仓库内 [迁移与研究接手提示词](迁移与研究接手提示词_20261116.md)，继续恢复真实模型、网页和研究基线。无需再向它粘贴长提示词。只配置而不启动可省略 `--start`。

源码和文字实验结论已在本分支，**不需要另外下载旧源码补丁包**。Git不包含模型、训练数据、候选权重或照片：Codex应先下载／核验约3.21GiB默认模型，按机器实际设备配置独立环境，先跑通真实服务；有条件时再从旧机搬现有数据和实验产物。旧资源的具体路径、大小、SHA256、复现公式、实验结果和后续方向都在接手说明中。

原机SSH别名 `yicloud` 不代表新服务器地址。新网页应由Codex按新机账号和端口生成SSH转发命令；仅监听服务器回环，不直接公开未鉴权推理接口。

Codex相关官方参考入口：[CLI](https://developers.openai.com/codex/cli)、[配置参考](https://developers.openai.com/codex/config-reference)。本次官方文档请求受原机出口403／超时影响，具体中转参数根据原机实际config核对，CLI版本根据原机 `codex --version` 固定；并非声称官方推荐该第三方服务。
