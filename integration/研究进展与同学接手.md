## 先看结论

正在执行[全量高清与RGB纹理训练](quality/20261124_全量高清数据与RGB纹理训练.md)：全部712张合格原生高清训练图、两组各4,000步、固定15图加20图扩展回归，同时最多一张H200。状态页`/age-native-full/`，最终复核页预留`/age-native-full-review/`；当前尚无本轮效果结论。新增142张训练图的同时，扩展保护组分组剔除了98张旧高清训练行。亚洲70+标签实际仅5张，原生纹理和年龄保护通过前不替换W+基线。712张数据的独立目录恢复、2,136张图片哈希及路径转换均已通过；结果归档完成后补充Release清单。

**11月24日接续优先读[高龄纹理单卡对照结果](quality/20261124_高龄纹理单卡对照结果.md)。** 新采集3,982张通用高龄原生图；共同分组审计修正了恢复旧训练池造成的潜在保护组关联，后续使用963张隔离训练清单，其中668张符合高清纹理门槛。新增500／2,000步的生成器高清重建与局部GAN配对研究，冻结原权重并用相同W+代码比较。两轮均未晋升；2,000步使密纹变平滑但高清组年龄响应仅保留约86%／87%，低于90%保护线。不要把旧1,754张合并清单当作独立身份划分，也不要把通用高龄采集称为亚洲高龄专项覆盖。

同日进一步完成[W+匹配训练](quality/20261124_Wplus匹配训练对照.md)和[年龄条件纹理／年龄保护](quality/20261124_年龄条件纹理与年龄保护.md)，各两臂1,000步。两项共用60张隔离训练图、15张固定开发回归和相同原W+代码；匹配训练更好保留基线，但原生密纹仍在。年龄条件适配的20／40岁零补丁输出已做60项逐像素一致检查。代表图人工审查尚未证明高龄自然度改善，候选保留研究状态。静态页面`/age-latent-match-review/`和`/age-conditional-texture-review/`供复查，不额外占GPU。

四个小型生成器参数补丁、冻结代码／训练日志、独立指标、来源审计及两张有署名的公开对照集中在[年龄条件研究Release](https://github.com/prummn/face-age-transformation-course-project/releases/tag/research-mobei-age-conditioned-2026-11-24)。这是部分生成器参数，不能当作完整SAM或替换编码器；条件补丁还必须按报告公式插值。下载到独立目录，不自动启用：

```bash
python3 integration/models/restore_research.py --manifest integration/models/age-conditioned-20261124.json --list
python3 integration/models/restore_research.py --manifest integration/models/age-conditioned-20261124.json --group evidence --group examples
# 只有复现实验需要四个参数补丁：另加 --group weights
```

数据试采从韩国官方原发布页取得3张原照，实际仅1个人、1张脸区尺寸合格、0张入训；拍摄日期与出生日期声明仍有待核验，全部隔离，不计为已补足亚洲高龄训练集。400张／200身份和同人跨龄组仍是待完成目标，细节、哈希、拒收原因和下一阶段要求见[数据分阶段计划](quality/20261124_高龄纹理数据与分阶段训练计划.md)。不要继续扩大尚未取得原生自然度收益的同一短跑配方，也不要把缺少数据当成已经证明的唯一原因。

11 月 23 日新增 273 张通过筛选的高清训练图。单卡对照中，数据扩充主要减小了跨龄色偏，局部更新 StyleGAN2 的增益很小。高龄源年龄校准改善了输入估龄，编码器的跨龄身份仍弱于当前 W+ 质量基线。此次源数据审计和真实高清跨龄同人验证记录在[亚洲人脸质量专项](quality/20261123_亚洲人脸质量专项.md)与[源年龄校准复验](quality/20261123_源年龄校准与跨龄同人验证.md)。

最后一项实验新增两批高清候选，用人工外观档训练年龄监督头，并训练 3,000 步 SAM 编码器。接手时从[高清数据与实照年龄监督](quality/20261123_高清数据与实照年龄监督.md)查看最终路线、评估、权重、来源清单和可复现命令。

我们已经把真实 SAM＋StyleGAN2 链路从昇腾工程适配到 NVIDIA CUDA，在仪电调度平台用最多一张 H200 完成部署、数据审计、若干有对照的短训练、逐照片潜变量优化与网页验收。没有改成滤镜或扩散模型。

**目前最明显的可见收益来自改善每张输入的同龄重建，再做受约束的跨龄编辑。** 它通过推理时优化 W+，不是得到一份“全体人都更好”的新生成器权重。新图需要重新拟合。原始混合推理仍是默认，已接受的质量基线需要显式启用 `constrained`；另有可选 `texture`。训练检查点单独保存，未覆盖原Release。

还没有证明完成亚洲专项适配。源条件偏差、75岁监督上限、侧脸／遮挡、低清照片的同龄反演、高龄纹理与偏色仍是主要问题。共享年龄分数不等于真实年龄精度，生成图不代表未来容貌。

## 只想看效果：无需GPU

需要 Git、Python3.10+ 和网络；不需要Torch、平台账号或GitHub登录。在新目录执行：

```bash
git clone --single-branch --branch dev/mobei-gan-portable-20261116 \
  https://github.com/prummn/face-age-transformation-course-project.git
cd face-age-transformation-course-project
python3 integration/models/restore_research.py
python3 integration/serve_hd_demo.py
```

浏览器访问 `http://127.0.0.1:65512/hd-demo.html`。如果部署在远程服务器，在自己电脑开SSH转发后访问；原仪电服务器的别名是 `yicloud`，新机器要换为自己的SSH配置：

```bash
ssh -N -o ExitOnForwardFailure=yes -o UpdateHostKeys=no \
  -L 127.0.0.1:28080:127.0.0.1:65512 yicloud
```

此时访问 `http://127.0.0.1:28080/hd-demo.html`。本地端口28080如果被系统保留，改用能绑定的端口。网页和推理接口始终只监听服务器回环。

页面包含24张高清正脸：7–9、15–19、20–29、40–49、50–69、70+六组，每组男女各2张。每张同龄／20／40／60／75，共120个年龄条件、240张原始／保色1024PNG。能筛选、对比、轮播、原生放大、下载及查看来源。原照人脸短边716–1848像素，避免把低清图片放大当高清。

这是**真实模型已生成的完整留档**。打开页面不占GPU，也不伪称即时推理；处理新照片另需恢复真实后端。没有可信的人种标签，页面展示外观多样性，不凭长相标族裔。儿童变老仍偏童脸加皱纹，失败结果保留。

## 实验与决策

| 工作 | 实际做法与结果 | 当前决定 |
|---|---|---|
| 部署和路线诊断 | CUDA参考算子、独立环境、路径适配；真实health/prepare/transform1024和清除会话验收。区分原混合与直接编码器路线。 | 可复现；路线差异不能算训练收益。 |
| 数据审计与补充 | 历史Megalith筛选约10043训练／431评估，但原数据实体不在本机。新核验1760张FFHQ成人候选，最终1054训练＋80回归；保留原生1024、真实512、人工年龄区间与伪年龄区别。 | 发布实际训练／回归1134张，原候选计划可查；未声称严格身份隔离或亚洲专项数据。 |
| 配对100步 | 仅编码器 vs 编码器＋生成器高分辨率调制仿射；各100步、batch2、相同采样。 | 同龄略改善，跨龄身份略退；生成器额外收益近零，均不晋升。 |
| 配对500步 | 跨龄身份权重0.1 vs0.5，其他相同。FFHQ跨龄SFace .72595→.73999；Release直接为.73512。 | 强约束缓解退化，但上传样例没有修好；不替换线上。 |
| 配对800步 | 更强重建／身份；编码器 vs 编码器＋64–1024生成器局部参数。FFHQ跨龄SFace .75200／.75302。 | 年龄变化有所减弱、生成器额外收益很小；不晋升。 |
| W+同龄重建与跨龄约束 | 网络冻结，200步重建锚点＋前8层180步修正。探索性上传样例同龄SFace约.55→.85；真实API1024／清除检查通过。 | 莫贝接受为基线v1，显式 `constrained`，新图逐图优化。 |
| 纹理候选 | 对年龄位移的第8–17层乘0.5，其他约束一致。探索12图＋追加11图＋真实API，再增加32张官方外部测试照。 | 可选 `texture`；新32图跨龄SFace .78603→.80287，128条件中仍26个下降。 |
| 低频颜色约束 | 针对看到的颜色问题，7诊断＋16复核，确定性配对；对照重复W+误差0。 | 复核色度误差下降9.66%，未过事前10%门槛；身份区间含零。不晋升、不增加服务模式。 |
| 高清演示 | 只按原照清晰／正脸／光照筛选后冻结，再生成24图全部结果；原生1024、原始／保色、浏览器全部验证。 | 独立演示集；旧低清难例继续保留，不能把换图算模型改善。 |

SFace是独立身份网络的诊断代理，不是人工身份保证；LPIPS和FairFace也参与优化。不同数据组／路线／计时范围不可混为一个总成绩。FFHQ与基础GAN预训练数据重叠，80图只能称回归集；APPA的Asian为发布方宽泛标签，小样本不是亚洲总体结论。

原始默认混合公式：`G(pSp(x)+avg+Eft(x,s)+E0(x,t)-E0(x,s))`。

当前质量基线：先从 `pSp(x)+avg+Eft(x,s)` 优化出锚点 `w*`，再以 `w*+Eft(x,t)-Eft(x,s)` 为目标做前8层约束。`texture`再将第8–17层位移乘0.5。两者都不是把原照贴到生成图里，也不会更新通用权重。每个年龄从同一原照独立生成，不级联。

## Release怎么取

```bash
# 列出分组及准确压缩大小；默认只下载高清演示。
python3 integration/models/restore_research.py --list
# 下载数值记录，不包含用户或APPA照片。
python3 integration/models/restore_research.py --group evidence
# 真实质量推理／训练的基础模型（复用旧Release，额外含IR-SE50、AlexNet、SFace）。
python3 integration/models/restore_research.py --group baseline
# 固定训练／FFHQ回归数据，附256输入、真实512参考、原生1024及可迁移清单。
python3 integration/models/restore_research.py --group data
# 可选：历史研究检查点，按实验下载，不会自动启用。
python3 integration/models/restore_research.py --group weights100
python3 integration/models/restore_research.py --group weights500
python3 integration/models/restore_research.py --group weights800
# 可组合选择；已有且SHA256相同的文件直接复用。
python3 integration/models/restore_research.py --group demo --group evidence --verify-only
```

下载器支持断点重试，核验每片、合并文件和解包文件SHA256；拒绝越界路径、未列文件、链接与同名不同内容的覆盖。缓存位于 `deployment/release-cache/`。清单固定在 [research-20261117.json](models/research-20261117.json)，Release也附同一份及 `SHA256SUMS`。大文件分片只是便于下载，并非额外模型。

基线并没有“新的W+通用检查点”，所以继续从原Release恢复相同4个模型。慢速质量模式还需IR-SE50／LPIPS，独立SFace只用于评价。`baseline`组复用旧Release的6个文件，不把旧27.3GiB全归档下载下来。

历史候选都采用直接编码器公式，生成器组还需配套补丁；**不要覆盖原始 `encoder_step1000.pt` 后继续套混合推理**。检查点不是包含优化器状态的精确断点续训包。800步候选等未证优，后续优先从原Release起点进行新单因素实验。

数据包恢复1054训练＋80FFHQ回归的原始像素，不附APPA照片、用户人像、其W+代码或身份特征。`deployment/shared-research/manifests/{train,eval}.portable.jsonl` 用仓库相对路径；恢复后生成当前机器的 `train.jsonl`、`eval.jsonl` 并记录改路径前后哈希，逐张像素文件哈希不变。原完整104图评价额外24张包含APPA／用户／作者资料，需自行按合法来源取得，不能假装本公开包已包含全部独立测试图。

公开证据包放在 `deployment/shared-research/evidence/`，含协议、训练步日志、候选哈希、指标、失败和最终平台状态；路径已脱敏为相对形式，排除逐用户图记录。`INDEX.json`同时记录原始／公开版文件哈希，不能用脱敏后字节伪称原报告哈希。原机完整原始记录继续保留。

数据与演示衍生图保留FFHQ的CC BY-NC-SA4.0、逐照片Flickr许可、FFHQ-Aging引用；模型和代码仍受各自上游条款约束。课程非商业共享不代表可商用；许可和逐图来源随包提供。

## 要继续研究时读什么

1. [高清数据与有限生成器配对实验](quality/20261113_高清数据与生成器配对实验.md)：数据质量、划分、直接／混合区别、100步全部对照。
2. [500步身份约束](quality/20261116_单卡身份约束实验.md)和[重建与潜变量改进](quality/20261116_重建与潜变量质量改进.md)：为什么单纯延长训练不够，基线怎么建立。
3. [基线与纹理候选](quality/20261117_基线与纹理年龄对照.md)、[新增32图与颜色试验](quality/20261117_新增外部人像测试.md)：追加复核、失败、未晋升理由和确定性问题。
4. [高清样例说明](quality/20261117_高清演示样例.md)：来源、筛选、真实结果和浏览器证据。
5. [详细迁移与研究接手提示词](迁移与研究接手提示词_20261116.md)：真实后端环境、路径、算子、GPU配置、公式、待办；本页与新Release是最新资源入口。

推荐下一步仍以GAN为主：校准源年龄／高龄监督，使用独立年龄诊断；针对同龄反演和跨龄身份做固定对照；补充合法高清、高龄、相关人群数据。既有训练没有可靠亚洲标签，不把分类器的族裔概率当身份真值。不要在这16张复核图上继续调颜色系数，不以共享估龄追分掩盖失真。

资源约束保持同时最多一张卡，限时任务结束即释放。训练当前配方峰值约15–16GiB，建议24GB单卡；W+高清演示本轮峰值约5.26GiB，显存只是Torch allocated，不含所有运行开销。H200不是必需，其他卡的速度必须实测。不要改共享环境、占他人设备或复制旧平台凭据。只读研究记录／已生成演示完全不需要GPU。
