# 100 步受控增强对照

2026-11-10，已完成两臂训练、完整 clean 回归和固定压力测试。**本轮没有测出稳定的增强收益，不替换线上权重。** 两组输出目视几乎一致，轻微的共享年龄评分变化不足以证明质量提升。实验 checkpoint 保留用于复现；当前演示继续使用原 ft_l1 与可切换的推理保色处理。

## 样本实际扩充了什么

从已筛选的 2,293 张训练原图各生成两个候选，共 4,586 次尝试。通过固定数值门限的变体为 2,610 张：993 张轻微照明变体、1,617 张高质量 JPEG 变体；拒绝 1,976 张。504 张原图没有合格变体，968 张各有一个，821 张各有两个。原图始终保留，采样人口仍为 **2,293 张原图**。

照明变体只改 Lab L：随机正负 1–3 的偏移与幅度 0.5–1.5 的线性渐变；JPEG 使用 quality 96–98、无色度子采样。变体继承原图的 parent、近重复候选组和 FairFace 分类期望伪年龄，不重新标年龄、不修改几何，不把衍生图计作新身份、真实年龄样本或新恢复的高分辨率细节。

保色门限制的是**增强新增的误差**，不能证明源图本身完整或适合训练。源数据仍可见反射填充、头发遮住双颊、低清晰度、强灯光等问题；例如全量预览中的 00047200、00049643、00017628。这些质量问题不是生成变体新造的，也没有被增强门全面解决。

## 两组的唯一处理差异

两组都是本次从原始 `ft_l1/encoder_step1000.pt` **重新运行**，不是复用上一轮 `colour_only` 的结果。新版将原图抽样、增强决定与 CPU target/flip 随机序列显式分离，和上一轮色度实验的随机数实现不同，因此跨实验直接相减不能隔离增强效果。

| 配置 | control | augmented |
|---|---:|---:|
| 训练步数 / batch size | 100 / 2 | 100 / 2 |
| 学习率 / seed | 1e-5 / 20261110 | 1e-5 / 20261110 |
| 损失 arm / 色度权重 | colour_only / 1 | colour_only / 1 |
| 同龄直接重建权重 | 0 | 0 |
| 采样原图 / 冻结验证 | 2,293 / 431 | 2,293 / 431 |
| 同一 accepted bank | 是 | 是 |
| 每次原图抽样后的增强概率 | 0 | 0.25 |
| 物理 NPU | 1 | 5 |

共同配置还包括：固定 decoder 和 pretrained encoder、冻结 encoder BatchNorm 统计量、伪年龄权重封顶采样、随机目标 20–75 岁及同龄条件；初始权重完全相同。增强输入的年龄条件、重建、身份和色度损失参照均来自未增强的同一原图，并应用相同翻转。JPEG 使用与样本验收一致的 Pillow 解码。

实际验证了 100 步所有 parent keys、flip flags、source age conditions、target age conditions 一一配对，初始 24×5 的全部指标完全相同。两份 plan 只有输出目录、物理卡/可见卡映射和增强概率不同。两臂均完成 100 步，0 跳步，无非有限 loss 或梯度。

每臂有 200 次原图曝光，实际涉及 **182 张不同原图**。增强臂 54 次抽中增强，其中 14 次因该原图没有合格变体回退；最终使用 **40 次增强，实际率 20%**，分别为照明 15 次、JPEG 25 次，涉及 40 张不同变体。该计数通过独立 RNG 回放逐步核对日志得到。不能把生成的 2,610 张变体说成这次已全部用于训练。

## Clean 固定回归结果

从之前冻结的 431 张验证图片按既有伪年龄区间轮选同样的 24 张，保留每张同龄、20、40、60、75 岁全部结果。该集合曾用于历史模型选择，是回归集，不是新的盲测集。

色差是固定双颊 ROI 的 Lab `sqrt(Δa²+Δb²)`，不等同于皮肤分割。下表跨龄汇总为 24×4=96 个输出；同龄项为 24 个输出。

按每张输入的四个跨龄输出先求平均，增强组减对照组为 **+0.005970**；输入照片级配对 bootstrap 95% 区间为 **[-0.012990, +0.024071]**，包含零。24 张中 10 张平均色差降低。这里重采样单位是输入照片，不是身份；同一人是否出现在多张照片中未核实，区间不代表独立人群保证。

FairFace 年龄网络和 ID 网络也参与了训练损失，相关分数只作为辅助诊断，不能以同一网络自评证明进步。全部 24×5 结果均保留，没有因为结果差删除样本。

## 目视与导出检查

目视检查了全部 24 张的同龄、20 岁、75 岁配对页，以及压力测试中的 00000557、00001163、00001892。两臂的颜色、面部轮廓与清晰度几乎相同，未看到可信的增强改善。20 岁输出常见过度平滑、眼镜或嘴部形态变化；75 岁仍有眼周偏红、衣服/背景偏紫、过密皱纹等现象。这些主要问题在两臂共同存在，不能归因于本轮增强新增，也没有被本轮解决。此处是工具辅助目视复核，不是已完成的人工盲评。
