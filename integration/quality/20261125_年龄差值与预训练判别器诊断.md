# 年龄差值与预训练判别器：冻结模型诊断

本项接续[712图全量高清训练](20261124_全量高清数据与RGB纹理训练.md)。该训练未解决高龄密纹，因此先分离推理年龄方向和通用真实人脸先验的作用，避免继续把所有问题归因于数据量。仍使用SAM／StyleGAN2和原Release权重；以下优化只改变逐图W+，不更新通用模型，不混合原照像素，不缩小目标年龄。

## 为什么要比较年龄差值

原部署默认是微调编码器同龄锚点加原SAM的年龄差值：

`G(pSp(x) + avg + Eft(x,s) + E0(x,t) - E0(x,s))`

此前莫贝接受的W+基线在改善同龄锚点后，采用微调编码器的年龄差值，再做180步前8层跨龄约束：

`G(w* + Eft(x,t) - Eft(x,s) + correction_ft)`

因此“同龄重建改善”不意味着“微调编码器年龄方向也更好”。本项固定同一个`w*`、原始生成器、源参考年龄、20／40／60／75目标、噪声与输出流程，只比较：

| 路线 | 初始目标代码 | 跨龄修正 |
|---|---|---|
| `wplus_base` | 原固定基线代码 | 复用基线已保存结果 |
| `original_delta` | `w* + E0(x,t) - E0(x,s)` | 无 |
| `original_delta_constrained` | 同上 | 180步，仅前8层 |

约束组沿用基线的身份.8、年龄KL.5、LPIPS.6、位移L2.05、低频颜色.1；学习率.012衰减至20%。其年龄teacher使用**历史混合公式的未优化锚点＋原SAM差值**，LPIPS参照使用新路线的初始输出。与基线相比不只替换一个最终PNG，也同步改变该方向对应的teacher／初始参照；不能把约束路线差异解释为严格的单个张量因果效应。未约束路线帮助观察完整原SAM方向，但它与已约束基线的优化预算不同。

源年龄等于目标年龄时直接使用同龄锚点，不再额外优化。所有网络参数在运行前后做指纹核对；所有基线以及各候选同龄PNG必须与父实验SHA256严格一致。FairFace源年龄和MiVOLO输出年龄均为外观估计，不能当真实拍摄年龄。
