# 人脸年龄模型颜色与数据审计

日期：2026-11-10。检查对象为服务器现有 `face-age` 数据、训练代码、六组历史评估结果和微调权重。原项目保持只读；统计和实验写入新的 integration 目录。初次审计后，已获准在物理 NPU 1/5 完成 control 与 colour_only 各 100 步小实验，候选权重未上线；没有占用服务 NPU 0/4 或保留设备 2/3。结果详见同目录[100步颜色约束实验](100步颜色约束实验.md)。

当前主要问题有明确证据：微调后的高龄结果比输入更暗、更红、更黄。现有 RGB/BGR 转换和归一化路径一致，训练代码也没有种族分类损失。更有根据的优化方向是限制每个人自己的色度漂移、改善低分辨率训练样本、控制伪年龄与颜色的混杂，同时保留身份和年龄变化效果。上线后的颜色保持后处理与下述模型训练实验是两件事；后处理改善不能被写成模型已经重新训练或精度提高。

## 颜色变化的配对测量

对六个历史 checkpoint 的相同 431 张评估照片、每张同龄重建及 20/40/60/80 岁结果做 CPU 统计，共 12,930 张生成图。使用 FFHQ 对齐坐标下两侧脸颊窗口的 Lab 中位数，计算输出减输入的变化。这里的区域是固定几何窗口，可能受头发、姿态、胡须影响，不是精确皮肤分割；统计的是既有图片颜色，不从图片推断种族。

以下数值均为样本均值；`|Δab|` 是逐图色度差的长度再取平均，不能由表中平均 Δa、Δb 反算。历史评估文件都是 256×256；原生 1024 的现场版本仍需另外核对。

| 权重 | 同龄色度差 | 60 岁色度差 | 80 岁色度差 | 历史变龄身份余弦 |
|---|---:|---:|---:|---:|
| 原始 SAM | 2.86 | 3.51 | 4.08 | 0.523 |
| ft_l1 step250 | 3.20 | 8.92 | 17.23 | 0.676 |
| ft_l1 step500 | 3.14 | 9.90 | 13.23 | 0.694 |
| ft_l1 step750 | 3.33 | 10.91 | 14.41 | 0.702 |
| ft_l1 step1000 当前默认 | 3.62 | 8.46 | 11.46 | 0.704 |
| ft_l5 step250 | 3.06 | 9.68 | 14.47 | 0.630 |

当前默认的 80 岁结果平均 ΔL=-3.30、Δa=+6.21、Δb=+9.07；60 岁为 -2.24、+4.53、+6.42。同龄重建已有一定误差，加入高龄条件后偏红、偏黄进一步增大。ft_l1 step1000 在已有微调权重中仍是较好的折中，切换到 ft_l5 不能解决偏色。原始 SAM 色度变化更小，但历史身份指标明显较低；不能只按单一颜色分数替换默认权重。身份指标使用训练时同一个网络，只能作为辅助诊断。

历史 `summary.json` 的 `collapse` 是 VLM 对外观群体分类概率的阈值计数，不是 GAN 模式坍塌、皮肤色差或客观身份保持指标，不应当作颜色修复的验收依据。本轮没有运行该分类器。

## 数据与清晰度

数据流程为 95,336 个候选 → 93,211 张下载后可检测图 → 18,617 张质量门通过 → 10,481 张分类器筛选成人 → 精确 dHash 去重后 10,478 张 → 成功对齐 10,474 张，其中训练 10,043、评估 431。缺失对齐图为 4 张，清单已记录。

| 源图中人脸短边 | 数量 | 占 10,478 张比例 |
|---|---:|---:|
| 小于 128 px | 3,913 | 37.3% |
| 小于 192 px | 8,000 | 76.4% |
| 小于 256 px | 9,532 | 91.0% |
| 小于 512 px | 10,465 | 99.9% |

人脸短边中位数仅 142.7 px，尽管原图尺寸中位数为 1023×768。全部对齐图为 256×256；训练和历史评估使用 `resize=True`，像素、感知与年龄监督只看 256 输出。当前原生 1024 的细节主要依赖预训练生成器先验，增大输出尺寸或超分不能证明恢复了输入中不存在的真实细节。

现有伪年龄分布如下，年龄是 FairFace 分类概率期望，并非真实年龄标签。

| 伪年龄区间 | 原始 index 数量 | 新质量清单数量 |
|---|---:|---:|
| 20–29 | 6,449 | 1,373 |
| 30–39 | 1,789 | 393 |
| 40–49 | 809 | 196 |
| 50–59 | 1,015 | 218 |
| 60–69 | 359 | 92 |
| 70–79 | 57 | 21 |

原数据没有儿童样本，伪年龄最小为 24.06；伪年龄 20–29 占 61.5%。已有来源标签的分类器概率更偏向 East Asian 的有 9,413 张，偏向 Southeast Asian 的有 1,065 张；这是过滤模型的记录，不是已核实的人群身份。没有 subject/identity 标识，无法证明训练和评估按人分离。

全体对齐图中，伪年龄与双颊 Lab 的相关系数为 L=-0.154、a=+0.254、b=+0.281。20–29 档平均 L/a/b 为 65.08/11.44/11.49，70–79 档为 59.95/15.67/20.46。年龄越高的样本总体更暗、更偏红黄，与模型输出方向一致，但这种相关不能单独证明偏色因果。

## 训练实现与风险定位

- 输入路径一致：训练 `cv2 BGR→RGB→[-1,1]`，服务为 `PIL RGB→[-1,1]`，输出 PNG 以 RGB 保存。没有发现红蓝通道交换或 ImageNet 均值方差索引错位；FairFace 标签索引也已对照本地 Parquet schema。
- 实际损失为年龄 MSE、变龄身份余弦、cycle L2/LPIPS/身份；没有 `l_eth` 或种族分类优化项。族群概率只用于数据过滤和日志。直接输入→变龄输出缺少颜色保持约束，cycle 重建可容忍可逆的颜色改变。
- 年龄网络仅有 9 个分类档，期望代表值最大 75，原训练却采样 5–90 岁目标。80/90 的目标高于这个监督头的输出上限；继续增大年龄权重可能强化颜色、纹理捷径，不能靠该年龄头证明高龄准确。
- FairFace 验证集年龄分类准确率约 0.59–0.61，±1 档约 0.96；checkpoint 按 race7 准确率保存，没有按年龄误差或颜色稳定性选模。过滤、年龄损失和年龄评价复用同一网络；训练用的身份网络又被用于评价，存在自评偏乐观的限制。
- FairFace 训练/过滤采用 resize + center crop，AgeEst 改为整个 FFHQ 对齐图缩至 224，存在裁剪域差异。应先统一并校准，不要把来源估龄直接当作真值。
- encoder 含 BatchNorm，每卡 batch=6，DDP 关闭 buffer 广播；其运行统计可能漂移。两轮历史训练实际均为 0 次跳步，不能把“发生过大量梯度跳步”当作解释。BatchNorm 风险仍需消融验证。

## 已生成的实验清单

`prepare_colour_experiment.py` 已实际运行，结果保存在服务器新目录；本地生成清单不纳入交付源码：

```text
/data/home/1120231322/scow/face-age-integration-20261110/quality-audit-20261110/colour_manifest_v1/
```

清单不改变原 split。近重复候选按原图 dHash256 汉明距离≤12、对齐图 pHash64 汉明距离≤6、同 Flickr 照片 ID 建组。任何包含旧 eval 的组，其 train 成员都隔离；eval 不因图片难或结果差而被剪掉。另按人脸短边≥192 px、对齐 Laplacian 方差≥40 筛选训练候选，并在剩余近重复组中保留质量较高的一张。

结果为训练 2,293 张、冻结 eval 431 张；27 个跨 split 候选组导致 43 张训练图隔离；另有 7,637 张源脸过小、23 张对齐清晰度不达门限、47 张组内候选重复被排除。近重复需要人工抽查，不能自动等同“同一身份泄露”。旧数据精确 dHash 去重只删除 3 张，近重复风险此前未覆盖。

`eval_frozen.jsonl` 给每张图记录 SHA-256；重跑若结果改变会拒绝覆写。train 与 eval 候选组不相交。这个 eval 已用于历史选择权重，只能称冻结回归集，不能称新盲测集，也不能保证不同照片的同一人不跨 split。采样权重按伪年龄档计算并封顶 3；重复采样不会增加那 21 张高龄样本的身份多样性，更不能填补缺失的儿童人群。

## 可执行颜色损失消融

`train_colour_ablation.py` 默认仅检查清单、初始 ft_l1 step1000 权重和冻结 eval 文件哈希并打印计划，不分配 NPU。真正训练必须显式带 `--execute`。

四组为 `control`、`colour_only`、`same_age_only`、`colour_same_age`。全部从 ft_l1 step1000 开始，冻结 decoder、pretrained encoder 和 encoder BatchNorm 运行统计；使用同一新清单、同一种限权重采样、20–75 岁实验目标范围、单卡 batch 2、学习率 1e-5、默认 100 步。control 包含这些共同变化，因此它是本次颜色损失消融对照，并非原始训练配置的复现。

颜色项是软面部区域内、16倍低通后的 YCbCr 色度 L1，目标是同一个人的原输入，不设置任何统一“亚洲肤色”。只约束 Cb/Cr，保留亮度和皱纹结构自由度。同龄项增加输入直接重建的 L2、LPIPS 和身份约束，保留原年龄、变龄身份和 cycle 损失。面部 mask 是几何近似，需检查头发、嘴部和背景污染。

每组在 step0 与保存点，对冻结集按现有伪年龄档轮转取固定 24 张，导出同龄/20/40/60/75 拼图、前 4 张的原生 1024 输出、配对 Lab 色差、同龄重建误差，以及标为辅助项的训练共享年龄/身份指标，另附空白盲评表。至少同时检查“像不像本人、颜色一致性、是否有年龄变化、纹理伪影”；不能只看 FairFace 数字选最佳。

已通过语法编译、冻结清单 dry-run、CPU 色度梯度检查以及 control/colour_only 两臂完整 NPU 训练与验证。相同图色度损失为 0，纯灰亮度偏移约 8.9e-10，红色偏移有非零损失和有限梯度。两臂各 100 步均无跳步；24 张冻结回归输入的四目标平均色度差下降 38.29%，但共享 ID 略降、共享估龄 MAE 略增，仍有视觉反例。same_age_only 和 colour_same_age 两臂没有执行。详见独立对照报告，不能将这次小实验等同全面验收。

复核命令如下，默认不会训练：

```bash
source /data/home/1120231322/scow/face-age-web/env.sh
python /data/home/1120231322/scow/face-age-integration-20261110/quality-audit-20261110/train_colour_ablation.py \
  --train-manifest /data/home/1120231322/scow/face-age-integration-20261110/quality-audit-20261110/colour_manifest_v1/train_manifest.jsonl \
  --eval-manifest /data/home/1120231322/scow/face-age-integration-20261110/quality-audit-20261110/colour_manifest_v1/eval_frozen.jsonl \
  --out /data/home/1120231322/scow/face-age-integration-20261110/quality-audit-20261110/future_colour_same_age_seed20261110 \
  --device npu:1 --arm colour_same_age
```

设备选择先解析 `ASCEND_RT_VISIBLE_DEVICES`，禁止物理 NPU 0、2、3。仅 `--execute` 路径查询 `npu-smi` 并确认目标空闲。比如可见列表为 `1` 时，逻辑 `npu:0` 正确对应物理 1；不能仅凭逻辑编号判断。所有实验输出必须在原 `face-age` 根目录之外。

最先值得补的数据是有明确来源、足够真实脸部像素、较丰富光照与肤色外观的高龄样本，并保留已知年龄/身份分组；应先补足稀疏档和验证集，再扩大总量。不要继续以提高外观群体分类概率替代颜色、年龄或身份质量。

统计细节见 `数据模型审计.json`；原始依据为服务器 `src/data_stage1.py`、`data_stage3a.py`、`data_stage3b.py`、`prep_align.py`、`faceattr.py`、`sam_losses.py`、`train_sam_ft.py`、`eval_sam.py`、`summarize.py`，以及 `data/index.parquet`、历史训练日志与 `out/eval_*/records.json` 和 PNG。
