# 明确年龄目标与身份约束：冻结SAM单卡对照

本项回应“高龄纹路减轻，但目标不够老”。沿用原Release SAM／StyleGAN2、已拟合源锚点和原SAM年龄差值，只优化逐图W+前8层，不训练网络权重、不改请求目标、不混合原图像素。独立MiVOLO只用于评估。

## 执行前固定的设计

1. 先用64376的同一原照两次独立完成200步源锚点拟合和180步目标拟合；使用已有确定性缩放／池化反向和CUDA确定性配置。要求源代码、目标代码和PNG哈希完全一致，否则停止正式对照。
2. 固定六张已看过的开发图：64376、62644、64919、65817、67140、60764。比较四种180步、batch2（60／75）、lr.012的配方，其他项相同。

| 路线 | 年龄项 | 年龄顺序 | 身份项 |
|---|---|---|---|
| teacher_control | 旧混合teacher分布KL，.5 | 无 | .8×(1−余弦) |
| target_age | 指定60／75对应分布KL，.5 | 无 | 同上 |
| target_age_order | 同上 | .25×正部(7.5岁−估龄差)/10岁 | 同上 |
| target_age_order_floor | 同上 | 同上 | .8×正部(同目标控制臂余弦−.01−当前余弦) |

分布由FairFace代表值[1,6,15,25,35,45,55,65,75]线性插值得到，60为55／65各半，75为最高档；分布期望必须恰等于请求60／75，不把75暗改90。年龄顺序项是同人60／75的共享头预测间隔下限；它不是独立真实年龄判据。身份下限使用ArcFace训练损失特征，最终还用独立SFace检查，二者不可互代。

3. 最后配方`target_age_order_floor`在看结果前就固定，与相同预算`teacher_control`继续评估其余29张既有回归图。中间两臂只在六图诊断，不能把六图均值当35图均值。整组都是已看过的开发回归，不冒称新盲测。
4. 全35图保留历史已接受结果`accepted_baseline`，175张基线PNG先逐文件复现；同龄／20／40及目标恰等于源年龄的结果必须保持哈希相同。60／75在同一固定锚点重新优化，不混淆历史batch4、当前batch2和线上逐请求拟合。
5. 六图记录年龄、身份、感知、颜色、信赖及顺序项的初始梯度范数，与年龄梯度／原SAM位移的方向关系。该信息只解释本配方初始位置，不代表整个180步或全部人群。

## 资源与验收

只申请一张GPU、4核／48GiB，45分钟硬上限。先停止本项目空闲演示任务并确认结束，保留CPU网关；实验结束后恢复原演示。没有新增数据下载、共享环境升级或自动换权重。

需完成：固定模型指纹、重复性、原始／保色1024 PNG解码与原始哈希、同龄／年轻保护、SFace、独立年龄误差及60→75变化、原生纹理／眼嘴检查。身份下降≤.02、相对跨度≥90%作为保护；高龄绝对外观误差和60→75变化也必须检查，不能只报相对保护通过。原生自然度未通过时不接入演示。

```bash
python3 integration/quality/age_objective_study.py prepare
python3 integration/quality/age_objective_study.py submit deployment/training-runs/age-objective-时间戳
```

开始阶段不改变线上`original_delta`。若明确目标仍只增加假纹理或损害本人特征，保留失败结果，不以单一估龄分数宣称成功。80／90岁不在本实验的可校准范围内。

## 六图机制诊断

以下只针对事前固定的六张开发图、60／75两个条件，不是35图全组结论。全部比较共用保存的源锚点；中间两臂没有扩展到其余29张。

| 六图路线 | 60／75 SFace | 60／75独立外观误差 |
|---|---:|---:|
| 历史接受结果留档 | .82476 | 14.4298 |
| 相同预算旧teacher对照 | .82952 | 14.3695 |
| 明确目标年龄 | .80456 | 10.0675 |
| 明确目标＋年龄顺序 | .80448 | 10.0355 |
| 明确目标＋顺序＋身份下限软惩罚 | .79847 | 9.4567 |

明确年龄目标确实改变了优化，但六图上的身份代价超过事前`.02`保护线；所谓身份下限是有限权重的hinge惩罚，不是保证可行的硬约束，ArcFace损失特征也不能替代独立SFace或肉眼的本人特征判断。

64376的75岁共享FairFace预测达到74.3，但独立MiVOLO仍约53.1；放松身份项后也仅约55.9，历史约54.0。62644／65817的独立分数提高较大，但全脸与局部对照同时存在眼形、嘴部和肤色变化，不能把分数提高直接换算为自然老化的改善。67140的同龄重建本来就丢失部分真实细纹／斑点，换目标损失没有修复这一输入反演问题。

六图中64376／62644／65817／67140的明确目标与追加顺序两臂，60及75的PNG完全相同；64919／60764仅初始记录点顺序项非零，后续记录点归零。同一个年龄头已满足顺序，并不保证独立外观或人眼也得到合理的60→75变化。

在64376的初始点，旧teacher年龄项梯度范数约`.402`，身份项约`.0842`，两者余弦`+.388`；沿原SAM位移的下降方向余弦分别`−.1071`／`−.1451`。这不能支持“身份损失一定占主导”的简单说法：旧teacher年龄项也可能回拉原年龄方向。测量只限这套配方的初始点，不概括全部180步或所有人。

固定六图之外的29图也出现相同取舍：历史／teacher／最后配方的60／75身份为`.80384／.80204／.77432`，外观误差`13.2618／13.2774／10.0738`，60→75变化`4.7893／4.7103／8.0855`。这29张是固定配方追加确认，但都是曾看过的开发回归，不是独立新身份盲测。

若把未改变的20／40也纳入跨龄均值，历史`.81295`与候选`.79847`的下降会被稀释到`.01448`，看似通过`.02`保护；只看实际变动的60／75，下降为`.02896`，三个分组均失败。因此本次同时要求全跨龄和高龄子集保护，不能靠大量未动条件稀释退步。

实际抽看64376／62644／65817／67140／60148／61908的全脸和代表性原生256局部。60148的眼形与笑容变化明显；61908口周形状、牙齿与脸颊线条仍不自然。64376的年龄分数与整体高龄感不一致，67140真实细节在源锚点已简化。部分图更老，但原生自然度没有可确认的普遍改善。这是可见路线的单人抽查，不冒充盲评或全图人工验收。
