# 技术路线诊断与改进建议（2026-11-12）

本记录回答当前生成流程、质量瓶颈、较新方法、课程约束及改进次序。依据当前 backend.py、历史训练脚本、数据审计、2026-11-12 两轮实际推理对照和下列原始文献；不是新模型已复现或已达到验收指标的声明。

## 当前实际流程

浏览器采集／上传并选脸 → 后端 YuNet 五点定位 → FFHQ 对齐到256 → FairFace 分类概率期望提供源年龄条件 s → 建立微调编码器同龄 W+ 锚点 → 为每个目标 t 计算原始 SAM 的年龄位移 → StyleGAN2 解码原生1024 → 可选色度后处理 → 浏览器回贴、对比、轮播和下载。

2026-11-12 后续决策：莫贝明确继续聚焦 GAN。当前执行固定样例的 SAM 路线消融、感知与身份约束反演，以及 CUSP 官方 GAN 权重对照；下文扩散文献仅保留为前次调研记录。线上继续使用已校验的原 Release 默认权重。通用编码器／生成器训练需要原训练数据与按身份划分的评估数据，不能以本次用户照片或作者演示图代替。

令 E0 为原 SAM 年龄编码器、Eft 为项目微调编码器，B 为上游配置指定的基础潜变量（本 Release 是 pSp 编码加 latent_avg），G 为冻结生成器。当前结果为：

`G(Eft(x,s) + B(x) + E0(x,t) - E0(x,s))`。

每个目标独立从同一输入生成，不将上一年龄的结果继续变老。镜子先定格生成，再把存储的脸跟随实时头部回贴；不会随实时表情重新生成。原始256输入和1024显示参考的取样路径不同，不能用“1024输出”说明输入的真实细节得到完整保留。

## 证据与待验证解释

| 问题 | 已有证据 | 解释的边界 |
|---|---|---|
| 同龄重建误差 | 源条件同龄已改变眼睑、嘴部、背景；逐照片 W+ 拟合可降低误差 | 有反演／表示瓶颈；尚不能区分全部生成器与编码器贡献 |
| 跨龄额外失真 | 用户图60/75的眼尾与眼袋生硬，多个推理路线共同存在 | 年龄与身份／纹理未充分解耦；不是已确定的单一人群成因 |
| 混合路线匹配 | 推理是 Eft 锚点 + E0 位移，历史训练／离线评测主要是直接 Eft | 位移移到不同锚点后可能不适配；这是需要消融的假设，不能说必然错误 |
| 数据细节不足 | 源脸短边中位142.7px，91%小于256；训练监督只看256 | 冻结生成器补出的1024纹理缺少个人高分辨率监督 |
| 年龄／数据覆盖 | 成人为主、青年占多数、高龄稀疏、伪标签 | 无法靠增加重复采样补足身份与年龄多样性；不代表基础 SAM 完全没有儿童能力 |
| 年龄监督上限 | FairFace九档代表值最高75，历史目标采样到90 | 75以上目标在该头下无法达成；这是监督问题，不等于生成器物理上不能生成更老外观 |
| 优化与验收目标 | 年龄分数、软身份约束、循环重建；缺少明确直接同龄重建项；训练与评价复用网络 | 循环还原不保证中间结果忠实；自评分数不能取代独立评价与人评 |
| 输入与回贴 | 用户图有逆光与反射填充；实时回贴使用定格表情 | 会加重局部问题，但不能解释所有 raw 生成失真 |

本次没有发现 RGB/BGR 混淆的证据，也没有进行原 NPU 与当前 CUDA 的逐像素算子对齐实测，不能据此宣称所有环境数值因素均被排除。

两轮逐照片潜变量实验中，用户图同龄中央脸部 MAE 从8.908降到4.241、3.705；第一版明显磨皮，第二版有所缓解。公开样例同龄参考估龄从当前混合53.14变为第一版36.09、第二版45.44。重建误差降低伴随年龄外观回退，证明不能仅靠像素指标选模型。见 `20261112推理与反演对照.md`。

## 较新的原始文献

查询日期2026-11-12。以下是研究候选，不声称存在跨全部输入、年龄、人群和速度预算统一最优的模型，也没有在本项目运行这些模型。

| 方法 | 来源 | 与当前问题的关系 |
|---|---|---|
| SAM，2021 | https://arxiv.org/abs/2102.02754 | 当前基线，快速且数值年龄条件直接，存在 GAN 反演与编辑性的折中 |
| FADING，2023预印本《Face Aging via Diffusion-based Editing》 | https://arxiv.org/abs/2309.11321 | 预训练扩散模型年龄适配、反演、优化 null-text embedding 和注意力局部编辑 |
| TimeBooth，ICCV2025 | https://openaccess.thecvf.com/content/ICCV2025/html/Su_TimeBooth_Disentangled_Facial_Invariant_Representation_for_Diverse_and_Personalized_Face_ICCV_2025_paper.html | 学习身份／年龄解耦表示，用图像形式 Age Prompt 提供更丰富的个性化老化信息 |
| Cradle2Cane，2025预印本 | https://arxiv.org/abs/2506.20977 | 少步扩散两阶段，分别加强年龄变化与身份保持 |
| Face Time Traveller，2026预印本 | https://arxiv.org/abs/2602.22819 | 属性感知提示、反演与自适应注意力，试图改善身份和背景保持；当前只核对摘要，不列为首选部署承诺 |

TimeBooth 论文声明代码入口 `https://github.com/szp-aigc/TimeBooth`；Cradle2Cane 声明代码入口 `https://github.com/byliutao/Cradle2Cane`。本次访问 GitHub／Hugging Face 超时，尚未完成当前公开 checkpoint、许可证、依赖与可复现实验的核验。论文声称优于已有方法，不等于本项目已验证它更好，也不等于直接用文本生成一个同年龄的新人物符合需求。

GAN 内也有改善反演与编辑性的方向（如 e4e、ReStyle、HyperStyle），以及逐照片微调生成器的 PTI 思路。它们不是可直接替换 SAM 的完整年龄模型；优化重建后仍需验证年龄位移兼容性。PTI 的逐照片生成器适配尤其不能被当成已完成通用人群适配。

## 哪些是需求约束

课程原始 `需求说明资料/02_课程与项目要求/whole_tasks.txt` 明确 D 要“根据现有年龄和人脸图像采用对抗生成网络模型生成多年龄目标人脸图像”。因此纯扩散替换最终 D 涉及课程选型口径变更，应让指导教师确认；离线比较扩散候选本身可以进行。

规范需求文档 v0.3 是评审草稿。FR08要求同一输入独立生成各目标，不级联上一结果；SAM 是首选候选、LATS 为对照，使用公开预训练模型范围为 Q2 待确认。文档没有要求必须使用 SAM2021、只能训练年龄编码器、冻结生成器、固定 FairFace、用现有低清数据或保持混合推理公式不变。RK3288 是镜子端条件，生成在 GPU 主机，不要求把大生成器硬塞到该设备；部分速度指标也仍待统一。

当前C只有分类概率期望产生连续年龄，不是单独的回归头；能否按DEX式期望满足“多分类与回归结合”，仍应对应Q1确认，不能因输出连续数值便宣称已有独立回归能力。

## 改进次序

1. 建立固定、获授权、多人、来源有记录的验证集；同龄、20/40/60/75全保留，儿童与80/90压力项单列。记录独立身份相似、独立年龄诊断、纹理／背景／颜色、人评和整批耗时，不用一个共享分数选优。
2. 在同一批原图上比较当前混合、直接微调与一项可复现的较新模型。先核对 checkpoint、许可证和目标接口；不凭论文宣传决定长训练。
3. 保留GAN路线时，优先验证直接同龄重建、感知／身份损失、足够真实像素的细节监督、有限背景与色度约束。验证不同反演表示的年龄编辑兼容性，避免纯像素拟合带来的磨皮。
4. 校准／替换年龄监督，修复最高代表值75与90岁目标的结构性矛盾。目标采样范围的实验变更须明确记录，不能改标签或把90映射75来声称问题消失。评价年龄网络与训练监督分开。
5. 整理高清、有年龄与人物标识、稀疏年龄段更丰富的数据，按身份隔离训练／验证；不要以分类器的人群概率提升替代质量。儿童数据和成人数据的能力分别验证。
6. 在改进编码器／反演的基线之上，做受约束的生成器适配对照：A仅编码器，B同配置加少量生成器可训练参数，严格比较身份、年龄、细节及原能力保持。不要一开始全量解冻，也不要只为单张用户图训练后宣称通用改善。

若现代模型在固定测试上明显占优且课程允许，更换D模型是合理选择；若课程坚持GAN，可保留GAN作为交付主线，以扩散作质量参考或经核验的数据辅助手段，但不能把扩散输出当真实跨龄标签。
