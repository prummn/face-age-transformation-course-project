# 高清数据与有限生成器适配：配对试验（2026-11-13）

莫贝确认开始执行。目的：区分推理路线差异、直接同龄重建监督收益，以及有限生成器适配的额外收益。保持 GAN 主线，不训练用户照片，不自动替换线上默认 Release。

## 预先固定的方案

数据候选：FFHQ 官方 training 1,280张、validation 80张，种子20261113；人工表观年龄区间20–29、30–39、40–49、50–69、70–120各均衡抽样，按发布者性别标签均衡。置信度≥0.6、源脸短边≥512、|yaw|≤20°、|pitch|≤15°、眼部遮挡≤15。保留原生1024、逐图来源／许可、官方文件MD5与像素MD5及本地SHA256。非商业课程研究按FFHQ／FFHQ-Aging及逐图许可处理，不把镜像当原始授权。

训练质量门：YuNet可检出、256人脸区域Laplacian方差≥25。评估困难样本不依此删除。相同Flickr账号或SFace余弦≥0.40连接为保守分组，训练中移除与validation、诊断照片或APPA测试相似的整个分组。**这不是已核实的身份标识，不能保证严格按身份隔离。** SFace只用于排重和独立身份诊断，不进入训练损失。

FFHQ图直接使用官方对齐，缩为256输入与真实512参考；512由原生1024下采样，绝不将256放大充作细节监督。数值源条件使用冻结FairFace期望年龄的四舍五入值，明确记为伪标签，保留人工年龄区间和置信度，不把区间中点标成真实岁数。

两个100步、batch2配对分支，均从Release的encoder_step1000.pt开始：

- A：仅更新SAM年龄编码器，lr=1e-5。
- B：相同编码器更新，另更新StyleGAN2的128–1024分辨率conv.modulation仿射参数，lr=1e-6；其他生成器参数冻结。

共同设置：种子20261113；按人工年龄档均衡抽取，再独立抽图和左右翻转；每步另采20–75连续目标条件。目标范围仅为本试验的明确边界，不修改线上5–90策略，也不表示75以上监督上限已解决。逐步记录相同照片索引、翻转、源／目标条件并核验两分支完全一致。100步batch2最多只访问200张，不是完整数据集训练一轮。

SAM直接路线 `G(pSp(x)+latent_avg+E(x,t))`。pSp、BN统计、FairFace、IR-SE50和LPIPS冻结；生成器噪声固定。共同损失：同龄MSE256 + 0.5 LPIPS256 + 0.1 ID + 0.2人脸加权L1_512；目标FairFace年龄MSE + 0.1目标ID + 0.01教师目标潜变量MSE；B另加0.1仿射参数初值MSE。单位不同的权重属于本轮固定试验设置，尚未宣称最优。没有新增判别器更新，是预训练GAN的受约束微调，不是从头对抗训练。

## 固定评价

对同一批输入比较：线上混合、直接微调初始基线、A、B。主要训练收益必须对照**直接微调初始基线**，不能仅对线上混合宣称收益。

每张生成同龄及20/40/60/75，独立运行各目标。80张FFHQ validation是**回归集**，因为基础StyleGAN2已用FFHQ预训练。12张APPA官方test、宽泛Asian发布者标注是额外评价，真实岁数与人评表观年龄分别保留；不是严格东亚身份盲测，不进入训练。用户图与11张CUSP作者样例仅诊断，原来已查看过，不作为独立泛化证据。APPA原图无法YuNet对齐的情况单独登记，不无声删除。

指标：独立SFace、同龄LPIPS／像素误差、脸部平均Lab色度漂移、共享FairFace目标误差及20→75响应跨度。共享网络指标不是独立年龄结论；跨龄像素／LPIPS会惩罚合理变老，不能作为重建收益。结合未保色raw图人工检查身份、嘴眼、纹理、头发和背景。所有输出计算指标并保存256预览；分层代表样本保留原生1024 PNG并复核解码，页面明确预览与原图区别。

### 已完成训练与候选使用

两组各100步，分别24.45／24.40秒，单组峰值已分配显存约14.8GiB。两组100批的索引、翻转、源／目标条件逐项完全一致；batch2共200次抽取，实际176张不同图片，**没有将1,054张都训练一遍**。A保持生成器冻结，B更新738,720个高分辨率调制仿射参数；编码器最大绝对更新约0.00061，B生成器最大绝对更新0.0000626。BN运行统计均与初值完全一致，训练损失及梯度有限。

候选位于 `deployment/training-runs/20261113-040634/encoder/encoder.pt` 与 `encoder_generator/encoder.pt`、`encoder_generator/generator_affines.pt`。每份编码器约1.0GiB，仿射补丁约2.8MiB；校验见同目录 `candidate-manifest.json`。原始SAM、pSp、latent_avg及其他生成器参数仍来自已校验Release。

候选按**直接编码器路线**评价，不能仅将文件改名覆盖线上encoder_step1000.pt，否则线上混合公式不会复现本轮候选。离线加载示意（x为[-1,1]、NCHW连续256输入）：

```python
net = load_sam('cuda:0').eval()
net.encoder.load_state_dict(torch.load(candidate / 'encoder.pt', map_location='cpu', weights_only=True))
with torch.no_grad():
    # 仅生成器候选加载此补丁；A没有此文件。
    if (candidate / 'generator_affines.pt').exists():
        named = dict(net.decoder.named_parameters())
        patch = torch.load(candidate / 'generator_affines.pt', map_location='cpu', weights_only=True)
        for name, value in patch.items():
            named[name].copy_(value)
    condition = torch.full_like(x[:, :1], target_age / 100)
    code = net.pretrained_encoder(x) + net.latent_avg + net.encoder(torch.cat([x, condition], 1))
    output = net(code, input_code=True, input_is_full=True, randomize_noise=False, resize=False)
```

`output`为原生1024；本段不用于改变现有线上服务。真实评价和网页对照在训练完成后继续执行。

## 实际评价结果

重跑任务最终 `Succeeded`，实验GPU已随任务结束释放；线上服务另行保持ready。104张输入×4路线×5条件共2,080个真实原生1024张量，均通过尺寸和有限值检查。保存2,080张256预览以及分层26张输入的520张原生1024 PNG，全部RGB／PNG解码复核通过。独立SFace没有缺失样本。全批评价372.90秒，含指标、PNG及共享盘I/O；暖机后目标编码＋解码中位约15.1ms，已排除源pSp／同龄锚点设置，**不是网页端到端请求延迟或冷启动耗时**。训练计时也不包含模型加载、环境创建和排队。

以下身份为独立SFace余弦（越高越好），LPIPS为共享网络同龄诊断（越低越好），20→75为共享FairFace响应跨度，非真实年龄精度。

| FFHQ80 · 线上混合 | .76797 | .67633 | .16661 | 1.7992 | 38.287 |

色度指标为中央人脸OpenCV 8位Lab的平均ab偏移范数，非DeltaE00。全部逐照片、逐目标、每组配对差值在 `summary.json`、`metrics.csv` 和 `evaluation/report.json`。描述性小样统计，不将图像级多目标当独立人物扩大显著性。

结果含义：

- 直接微调初始相较线上混合的跨龄身份改善明显，但这只是推理路线差异；没有把它记作本轮训练收益。
- A对直接微调基线的同龄LPIPS平均下降约2.2%（FFHQ）／3.3%（APPA），同龄SFace分别+.0030／+.0056；色度偏移略减。与此同时跨龄SFace分别-.0024／-.0030，诊断12图跨龄-.0116；不能宣称全面提升。
- 20→75共享估龄响应更强，跨龄身份却略降，体现年龄变化／身份保持的折中。FairFace本身参与训练，分数改善有自评偏差，不能证明目标岁数准确。
- B与A几乎相同。全104图×5条件的SFace绝对差均值约0.00075；本轮少量仿射参数／1e-6学习率／100步没有可见的稳定额外收益。这不能推断“生成器适配无用”，也不能据此直接全量解冻。
- 用户图同龄身份约.545→.554，但40／60／75身份约.636/.629/.581→.613/.601/.551。目视仍有嘴眼重构、肤质与眼下纹理不自然，原始输入的局部轮廓丢失未解决。不能说已修好用户反馈。
- APPA源照片的FairFace年龄对发布者真实年龄MAE约9.74岁，对人评表观年龄MAE约5.91岁；12张选择小样不能代表总体。高龄有明显低估，例如发布者76岁的源图估60.9，85岁源图估65.6。源条件／同龄监督偏差与生成器能力需要分开处理。

人工只抽查用户图、APPA_005762和APPA_005614总览：20岁目标仍有明显脸形／五官变化，同龄重建与表情也有残差；A/B目视差异很小。未逐图挑选成功案例、未用保色掩盖raw问题。其他104图均可在页面切换查看。

## 下一轮建议

本轮不推荐B替换线上，也不建议仅延长同一共享年龄损失来追分。优先用已固定评估集把源条件错误、同龄反演损失、年龄位移导致的身份损失分别定位；在下一轮控制实验中校准／改造年龄监督，同时加强跨龄身份约束，再决定生成器更新范围。若要检验更强生成器适配，需单独比较受约束低秩或局部参数更新、加入保持原能力的蒸馏，维持共同初始与采样；不能把单照片PTI结果说成通用亚洲适配。当前FFHQ缺可靠亚洲标识，亚洲专项高清／高龄数据仍需继续补充，不能据此轮宣称已完成专项训练。
