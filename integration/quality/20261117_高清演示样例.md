# 高清演示样例（2026-11-17）

## 目的与边界

莫贝指出新增测试照片模糊，要求 demo 包含男女老少、多样人群，优先高清正脸。前一批 APPA 官方测试32张中26张原始人脸短边不足256，且研究对照页使用256缩略图；1024输出不能恢复原照不存在的细节。旧 `/external-review/` 仍保留作难例评测，本次单独建设 `/hd-demo.html` 演示集。

本次不训练、不更换Release权重、不调整目标年龄策略。使用已接受的 `sam-wplus-v1` / `constrained`：同龄W+锚点200步，各目标前8层180步；直接调用实际服务的 `LatentQuality.run`，各网络冻结。每张照片生成同龄与20/40/60/75，并单独保留原始与可选保色PNG。这是离线留档，浏览时不伪装成新发起的API推理。

## 原照选择

来源：NVIDIA FFHQ 官方1024 PNG，FFHQ-Aging的人工外观年龄／性别标注。复用现有成人高清库，仅按HTTP精确范围读取缺少的儿童／青少年PNG，没有下载约95GB整包。官方完整元数据MD5、标注SHA256、每张PNG的文件MD5、像素MD5、尺寸、RGB及本地SHA256均核验；下载失败先查网络，复用已完成文件。

- 24张：7–9、15–19、20–29、40–49、50–69、70+六组，各组男女各2张，总计各12张。
- 原始大图中的人脸短边至少700，实际716–1848，中位860。不会只以文件尺寸1024认定高清。
- 来源标注yaw/pitch/roll绝对值均不超过10度；无眼镜，眼部遮挡小于5%，外观年龄区间置信度至少.65。
- 原照512脸部区域拉普拉斯方差至少140、均值亮度60–210，极端亮暗像素少于6%；最终实际清晰度150.45–786.81。
- 在清晰候选中兼顾原照局部亮度差异，随后只看原照排除彩绘、深帽檐阴影、逆光、邻人裁切干扰，记录8个排除及3个替换。阈值由160放宽到140发生在生成之前，人工检查确认替代儿童图仍可清楚分辨皮肤、发丝；没有按模型结果挑选。
- 未选入近期课程微调的 `train.pre-age.jsonl`；FFHQ仍与基础生成器预训练数据重叠，所以不是独立盲测。

数据没有可靠的人种／族裔标签。人群外观和肤色尽量多样，但亮度还受光照影响，不能把它当肤色真值，更不能宣称已覆盖所有人种。页面不按长相推断族裔。儿童／青少年属于成人为主的课程训练之外的展示范围，不以参考估龄或生成目标证明真实年龄准确。

原照选择留档：`deployment/demo-hd/20261117-reviewed/`。冻结 `inputs.json` SHA256：`94801657386f5d0feef93735993d396502e124742b3e56ea012680d75d66366b`。原照总览 `source-contact.jpg`，详细来源和人工排除原因见 `selection.json`、`inputs.json`。早期source-only筛选与缓存仍保留，无生成后重选。

结果及最终平台状态以该目录 `report.json`、`DONE`、`native-validation.json`、`browser-validation.json`、`platform-final.json` 为准。计时为GPU容器内实际服务helper，含W+拟合，分别记录冷启动；不是HTTP／网页完整请求耗时。CUDA原生优化可能有微小重复差异，固定seed不保证位级确定性。本次未修改服务算子以强求重复。

## 网页与重启

沿用本机回环网关65512及原SSH隧道。在原浏览器地址后加 `/hd-demo.html`，或原demo“选项”内点“查看高清人像样例”。页面有年龄／来源性别筛选、同龄／20／40／60／75、原始／保色、原照对比、轮播、1024像素原图预览与PNG下载。主对比直接读取1024PNG，人物列表用512缩略图，不把256研究预览放大为高清。URL保留当前人像／目标／色彩，方便分享同一结果。

```bash
# 构建／恢复静态图片链接，不需要GPU。
python3 integration/quality/build_hd_demo.py deployment/demo-hd/20261117-110722
# 需要重启网页时执行；已存在则复用本项目进程。
python3 integration/serve_hd_demo.py
# 检查已生成的真实图片与网页，使用本机已有Playwright环境。
deployment/control-venv/bin/python integration/quality/verify_hd_demo.py \
  deployment/demo-hd/20261117-110722
```

重新生成需要先恢复官方元数据、来源照片和原始权重，不将照片提交Git。核验选择文件后再提交一个有上限任务：

```bash
python3 integration/quality/submit_hd_demo.py --data deployment/demo-hd/20261117-reviewed
```

`原型/hd-demo-assets` 是忽略的本地符号链接，只指向已生成 `results/`，不公开模型、用户上传或平台凭据。样例附Flickr作者、原链接、原照许可证及FFHQ非商业署名／相同许可要求，说明裁剪、年龄生成和保色变更；课程演示允许的使用范围不自动扩展为商业授权。
