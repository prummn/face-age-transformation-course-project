搜索地区只用于安排来源覆盖，不能由姓名、国籍或照片推断族裔。出生日期和照片日期目前都是发布来源的声明，不是假定已独立核实的真实年龄。66个来源人物也不是66个已获可用照片的身份。

Commons API在搜索阶段返回HTTP429，已停止该来源请求并保存`rate-limit-stop.json`。此前Wikidata TLS超时后，复用了已有记录及已缓存的英文百科出生日期模板；旧响应没有版本ID的，保留空值、页面名、模板、缓存文件及SHA256，不伪造版本号。原Flickr发布页的一次独立访问也在TLS握手阶段超时。本轮没有继续请求Wikimedia原图或绕过限流。

核查同时修复了采集脚本的实质错误：请求未包含`mime`／版本ID字段；旧缓存缺少`mime`时误把全部结果拒收；`Taken on 16 May 2019`等日期格式未被解析。另加旧照扫描时间和壁画筛查，避免把1962年旧照的2017年扫描日期当成高龄拍摄日期。修复后仍全部处于隔离区。

来源文本筛查发现：一张裁剪标题指向Kumiko Goto而搜索目标为Yōji Yamada，一张描述明确为Miu Eng而搜索目标为Nobuko Miyamoto，另有一张描述禁止修改、与显示的CC许可冲突，均不用于训练。两张TFF演出照片与拟搜索演员的同名关联缺少权威依据，继续隔离；没有根据人脸像素声称识别了其中的人。

本次计数不包含前一轮的9张Commons原照和韩国官网3张原照，旧产物保留。后者只有1个来源人物，不能作为多身份增量。本轮的候选元数据也不能与这些旧下载相加，声称补齐了训练配额。

## 已交付的路线隐藏评审

本机页面：`http://127.0.0.1:65512/age-texture-blind-review/`。用户电脑复用既有SSH别名：

```powershell
ssh -N -o ExitOnForwardFailure=yes -o UpdateHostKeys=no -L 127.0.0.1:16512:127.0.0.1:65512 yicloud
```

打开`http://localhost:16512/age-texture-blind-review/`。页面是已生成结果的评审，不需要GPU即时推理。不要把这个页面可用说成上传推理服务在线。

来自`personalized-generator-confirm-20261125-055616`已有25张高清开发输入，每张属于不同保守来源组，但这些组不等于经过实名核验的身份。每图分别比较原SAM差值＋约束基线与逐图重建补丁、逐图邻域保护补丁的75岁原始输出，共50组配对，另加5组左右反转的重复检查。共有100张原生1024 PNG，逐张检查输出报告SHA256与解码尺寸，附300张直接裁剪的眼周／脸颊／口周图。文件和显示均不放大小裁剪。

网页只显示原照、左图、右图，不暴露路线文件名或私有分配表。每题分别选择纹理自然度、本人特征、目标年龄外观，记录左右严重伪影；允许持平和无法判断。进度保存在当前浏览器，完成后下载JSON。不同评审使用不同编号，在独立浏览器／浏览器配置中填写，完成前不看有路线名的页面或相互讨论。**目前0份人工评审，浏览器自动填写只是测试，没有计作人的评价。**

工作目录：`deployment/reviews/texture-blind-20261125`。`public/`是唯一挂到网页的子目录；`private-key.json`在其外且权限0600。网页请求该私有键返回404。不要把私有分配表交给评审或提交到仓库。

这是对**已看过的开发输入**隐藏路线标签，不能据此声称新身份独立测试。75岁是本轮主要诊断目标，年龄外观评分不表示真实年龄准确或未来容貌预测。尚需至少2名独立评审完成，才能按预先固定的规则汇总；工具不自动晋升模型。

```bash
# 收齐各评审导出的JSON后，在服务器汇总；输出可重定向到本地研究目录。
python3 integration/quality/build_blind_texture_review.py score \
  deployment/reviews/texture-blind-20261125 \
  --answers /实际目录/reviewer01.json /实际目录/reviewer02.json
```

重复题只评一致性，不计入效果样本。每位评审对每个来源组／候选只有一个主要投票，按候选分别报告25组多数偏好、持平／无法判断、严重伪影和评审完成度。拒绝重复评审编号、错研究ID、未知题号和无效答案。人评纹理与年龄／身份数值保护项共同验收，不能用SFace升高冒充皮纹改善。
