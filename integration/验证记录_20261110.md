## 实测与来源

本次模型为 SAM / StyleGAN2 的 `ft_l1` 第 1000 步编码器，估龄为 FairFace 分类期望；`regression=null`，没有伪造独立回归。原生输出使用 `resize=False`。服务器为 Ascend 910B3，使用空闲 NPU 0，服务冷启动至预热完成观测为 37.8 秒。

真实测试输入来自 [MediaPipe 官方公开测试素材](https://storage.googleapis.com/mediapipe-assets/portrait.jpg)。该样例参考估龄为 53，默认目标为 38、63、78、90；每个目标均从同一输入生成。原生下载用 PNG 头部读取确认 1024×1024，并记录文件散列。模型耗时与端到端耗时另列于 [机器可读验证摘要](验证摘要_20261110.json)；少量单样例观察不能作为 P95 或准确率结论。

双脸素材为同一公开肖像的两个不同大小、其中一个镜像的实例，用于验证空间选择不被最大脸覆盖，未证明不同人物的身份保持。首轮使用远景全身图时，较小右脸被前端漏检；改成面部近裁切后选脸流程通过。该现象作为检测范围限制保留，不能说已修复远景小脸检测。演示建议使用清晰近景照，未检测到的人物需换图或重新取景。

## 过程中修复的问题

- 启动检查完整读取 `npu-smi` 输出，避免管道提前结束造成空闲 NPU 被误判占用。
- 真实结果不再沿用 256×256 保存画布，展示、局部对比与原生下载保留 1024。
- 服务端匹配用户选中的人脸，返回训练一致的 FFHQ 几何；前端在相同坐标下对比和回贴。
- 取消准备时保留请求以清理迟到会话，并在等待清理前绑定本次序列，防止旧会话覆盖新照片。
- 提前查看结果后，补齐后续完成的年龄页；保留用户当前浏览位置。

## 复现

启动真实整合服务后，在仓库根目录运行：

```bash
python3 -m unittest discover -s integration/tests -p test_gateway.py -v
python3 -m unittest discover -s integration/tests -p test_backend.py -v
node integration/tests/integration-flow.cjs
```

后端测试需 NumPy、Pillow、FastAPI、httpx 等运行环境，可在已有服务器虚拟环境中运行；不会加载真实 NPU 模型。浏览器测试需 Playwright、Chromium/Chrome，录屏还需 Playwright ffmpeg；可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定路径，或 `QA_VIDEO=0` 关闭录屏。每次结果写入被 Git 忽略的 `tmp/integration-qa/`，`latest.json` 指向最终结果。自动测试不会把素材或录屏提交到公开仓库。
