# 时空镜：手机交互原型

更新：2026-10-29。当前 HTML 在同学的 v5 原型上继续迭代，采用已讨论的 A+B 组合：全屏镜头入口 + 横向年龄扉页。取景铺满当前视口，快门居中；相册与翻转镜头使用图标，模式、轮廓开关、检测状态和清除数据收进右上角“选项”。正常状态不堆叠技术小字，错误、倒计时与多人选择按需出现。旧版内容可从 Git 历史查看，同学原有的 Word 使用说明保留原样；当前行为以本文为准。

## 启动与手机演示

在项目根目录运行：

```powershell
python 原型/serve.py
```

电脑打开 http://localhost:65512/ 。页面和约 23 MB 的检测资源均从本地目录加载，无须 npm 安装；第一次检测需初始化 WASM 和模型。直接双击 HTML 也可以打开界面，但会尝试在线运行库，离线演示请使用配套服务器。

同一局域网的手机，可运行 `python 原型/serve.py --bind 0.0.0.0`，通过电脑的局域网 IP 和端口访问。这个 HTTP 地址可用于上传照片演示；手机浏览器调用摄像头需要可信 HTTPS。手机中的 localhost 指手机本身，不能用它连接电脑。需要实时摄像头演示时，应将整个 `原型` 目录部署到 HTTPS 静态站点，或配置受手机信任的本地 HTTPS；模型文件路径须一起保留。

## 一次完整体验

1. 默认手动拍摄。点底部中央快门开启镜头，或点左下相册图标选择照片；开启后右下图标可翻转镜头。镜头权限失败时会提示原因，可以上传继续。支持 JPG / PNG / WEBP，最多 15 MB，短边至少 256 像素；上传的大图按最长边 1800 像素缩小以控制手机内存。
2. 相册照片先进入选人页面。多张脸通过轮廓或编号选择，单张脸默认选中。检测失败可以拖动画框，再确认。实时取景也能点选人脸；镜子模式默认选择较大、较居中的脸。最多检测 4 张脸。
3. 确认照片后检查亮度、清晰度和姿态提示。自动检测时按眼线裁剪对齐到 256×256，并保存逆变换参数；手动框选仅按区域裁剪，不伪造关键点或朝向检查。质量阈值为原型启发式，仍需实机标定。
4. 填写当前年龄（1–99 岁），选择 1–8 个目标（5–90 岁）。自定义年龄、增加/减少年数、每十岁、人生阶段和 +10/+20/+40 年集中在“更多年龄选项”；快速组合会替换现有目标，仍可删除或补充。照片检查指标另行折叠，默认只显示完成操作所需的信息。
5. 制作后左右滑动年龄手记，也可用箭头或圆点翻页。原照作为首个“此刻”页面，目标按年龄排列；自动翻阅按年龄从小到大循环。点按目标照片打开分割线对比，可切换人脸局部与回贴原图。
6. “年龄总览”提供按年龄排序的拼图及 PNG 导出。“保存 / 分享这一页”优先尝试系统文件分享，不支持时下载 PNG。文件始终带年龄与演示属性标注；分享面板是否出现由手机浏览器决定。
7. 处理状态页显示每个目标的排队、处理、完成、失败及实际耗时；单个失败不阻塞其他目标，可单项重试。默认接口超时为 60 秒。右上角“选项”中的“清除本次数据”会停镜头、停播放、失效待处理任务，并清掉内存中的原图、结果与画布像素；已导出文件保留。拍摄方式与面部区域开关也在该面板内。

## 手机与镜子模式

手机模式由用户拍摄，拍摄完成后关闭摄像头，查看结果期间不会因离开镜头而清空。镜子模式保留视频检测，稳定约 1.8 秒后进入 3 秒倒计时；选中人脸消失约 5 秒后清空。稳定与大小阈值需按目标设备标定。

默认未接估龄模型，镜子拍摄后也需填写年龄。接入真实估龄适配器并得到可用结果后，才可自动选择目标并继续。当前镜子模式属于网页流程验证，不代表 RK3288 Android 应用已完成。

## 轮廓、分割与模型边界

- Face Landmarker 自带检测能力，主流程只运行这一套模型，每秒至多检测 5 次，CPU 推理；不额外叠加一次 BlazeFace。轮廓使用 36 个面部椭圆关键点，选中区域可半透明填色。
- **这实现的是逐人脸几何区域掩膜，尚未实现用户所提完整的实例分割。** 不包含头发、耳朵或身体的像素级语义，也不是生物身份识别。目标编号靠短时位置匹配保持，遮挡或交叉时可能需要重选。
- 轮廓模型失败且运行库可用时尝试内嵌 BlazeFace，降级为检测框；全部不可用时仍能手动框选。
- 当前没有真实年龄估计与 GAN。默认年龄手动填写，变龄是演示滤镜。已去掉随机估龄数值；界面和导出均注明演示属性，不能拿来证明模型精度、身份保持或真实年龄变化。
- 本地默认流程不上传照片、不使用 localStorage / IndexedDB 持久化照片；运行库联网兜底会下载资源。未来接入服务后，应按实际网络和服务端保留策略修改说明。清除是应用层释放与像素清空，不保证浏览器底层内存的物理安全擦除。

## 模型接入位置

可在页面启动后、操作前挂载 `window.AgeMirrorAdapters`：

```javascript
window.AgeMirrorAdapters = {
  // 输入：256×256 对齐人脸 canvas；须由实际模型返回年龄。
  estimate: async (image) => ({age: 28, probabilities: [], regression: 28}),
  // 每个目标独立从同一输入生成；返回 canvas、ImageBitmap 或已解码的 Image。
  generate: async ({image, sourceAge, targetAge, requestId}) => resultCanvas
};
```

上段仅说明接口形状，数字不是已接入模型的输出。实际对接必须实现模型调用、输入归一化、输出解码、服务错误和数据策略；当前没有局域网 HTTP 协议实现。单次生成默认 60 秒超时，迟到的返回图像会丢弃；清除/取消后不会写入新会话，但已经提交的外部工作需要服务本身支持取消。
