# 前端验证记录

环境：Windows，Playwright + Chromium 1243，2026-10-29。使用浏览器真实MediaPipe模型；照片取自官方公开测试素材，测试文件只放在被Git忽略的tmp，不作为产品示例或训练数据共享。

| 检查 | 方式 | 结果与限制 |
|---|---|---|
| 单脸轮廓 | 阻断全部HTTPS请求，通过配套HTTP服务器上传官方portrait.jpg | 本地Face Landmarker返回1张脸与36点轮廓，无需外网 |
| 多人选择 | 将测试肖像并列组成双脸照片，真实模型检测 | 返回2脸，初始需选择，点第二编号后进入对应裁剪 |
| 实时轮廓与拍照 | 已解码照片经canvas.captureStream产生模拟视频，仍运行真实模型 | 实时获得轮廓，拍摄后关闭手机模式视频流；不是物理摄像头/手机实测 |
| 模型失败 | 阻断本地模型和外网，真实鼠标拖框 | 可确认手动区域并进入年龄输入 |
| 相机拒绝 | 无授权浏览器上下文启动镜头 | 给出可上传的错误提示 |
| 年龄与边界回归 | 空目标、最多8项、相对-10年、手动年龄编辑 | 空值不会变成5岁，不能加入第9项，年差正确 |
| 结果与导出 | 上传→选脸→手填→5目标→扉页→对比→回贴→PNG→总览 | 6页含原照，导航正确，PNG非空可解码，6格总览 |
| 故障隔离 | 注入某目标失败、修复后点重试、短超时适配器 | 其他目标保留，失败可单独恢复，超时为失败而非假成功 |
| 异步与清除 | 清除后迟到生成、估龄迟到、任务派发前清除 | 不写入新会话；手填40不被迟到30覆盖；清除后的排队任务不提交 |
| 图像释放 | 检查状态引用、对比临时图、所有DOM画布及脱离DOM的检测缓冲 | 清除后引用复位且像素alpha清零；不宣称浏览器物理内存安全擦除 |
| 响应式 | 390×844流程截图；320×568、844×390、1280×900总览宽度 | 流程截图人工查看；所测尺寸无页面横向溢出。未逐机逐页穷举。 |
| 全屏取景修订 | 320×568、390×844、430×932、844×390、1440×900测量 | 镜面铺满视口、水平居中，快门首屏可见；模式设置默认折叠，无横向溢出。手机与桌面实际截图已查看，真实手机安全区仍待实机检查。 |

桌面显示修正：1440×900窗口下使用居中的390:844手机比例预览，取景、导航和选项限制在预览内；手机窄屏继续全屏。已更新尺寸回归检查，替代此前“桌面也铺满整个窗口”的判定。

测试源位于 [tests](tests/README.md)。尚需组员实机验证：iOS Safari / Android Chrome的相机权限、前后镜头、真实动态多人脸、手指滑动、系统分享、设备温升与时延、镜子自动采集/离开清空，以及RK3288兼容性。照片上传的成功不能代替这些实机项目。
