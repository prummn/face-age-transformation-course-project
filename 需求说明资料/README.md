本文件夹集中保存此前整理的需求规格说明、课程要求和需求阶段调研材料，便于组内统一查看。资料已从根目录归并至此，原稿与规范版分别保留，根目录重复副本已清理；修改历史保存在Git中。

## 目录

- `01_需求规格说明书/`
  - `人脸年龄变换系统_软件需求规格说明书.docx`：同学原始初稿，原样保留。
  - `人脸年龄变换系统_软件需求规格说明书_规范版.docx`：按《附录 G-2 产品需求规格说明书》整理的 v0.3 评审草稿。
  - `需求规格说明书_规范化说明.md`：章节映射、表述校正和待确认事项。
- `02_课程与项目要求/`
  - `Projects.pdf`：课程项目总体要求。
  - `requirements_on_2026_10_21.txt`：课堂讨论要求。
  - `whole_tasks.txt`：本组 A-E 分点任务。
- `03_调研与检索材料/`
  - 课堂讨论速览、详细报告、项目理解与检索报告。
  - 同学需求调研 PPT、内容核对记录、来源清单和检索记录。

## 阅读顺序

1. 先看 `01_需求规格说明书/人脸年龄变换系统_软件需求规格说明书_规范版.docx`。
2. 再看同目录的 `需求规格说明书_规范化说明.md`，核对尚未确认的范围、性能和训练记录。
3. 用 `02_课程与项目要求/` 核对课程交付物和 A-E 任务。
4. 最后查看 `03_调研与检索材料/` 的详细报告和检索记录。
