# 镜面优先的手机界面调整

用户本轮反馈明确要求：镜面居中并覆盖手机大部分屏幕，删除冗余小字，采用简约、清晰、内容优先的交互。延续已授权的A+B设计与浏览器预览，在现有目录直接迭代。

1. 编写视口回归检查，先确认旧版镜面占比与首屏操作不符合要求。
2. 去掉500px应用限宽与450px镜面限高；取景页使用100dvh镜面，顶部与底部浮动操作。模式、轮廓、技术状态与清除归入选项，提示仅在加载、多人选择、倒计时或错误时显示。
3. 统一后续页面的留白、字体、主次按钮和图片尺寸，移除营销文案、英文编号和重复说明；演示属性保留一个简短标识，完整说明与导出标注不删。
4. 验证320/390/430宽手机、桌面与横屏；实际截图检查、模型流程与触摸翻页回归，更新说明并同步已授权的组内仓库。

不调整检测模型、真实估龄/GAN边界和原始课程文件；不新建重复工作区。
